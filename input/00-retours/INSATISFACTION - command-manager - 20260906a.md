# Insatisfaction — les login et mots de passe sont affichés sur la page d'accueil

Il ne faut pas mettre les login et mots de passe sur la page d'accueil : l'appli est directement disponible sur Internet. Il faut les insérer dans le fichier .env pour que le développeur puisse les récupérer directement et les modifier à loisir.
