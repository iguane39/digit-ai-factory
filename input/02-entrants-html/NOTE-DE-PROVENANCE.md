# Entrants HTML — note de provenance

Ce dossier a porté, du 17/08 au 27/08/2026, **quatre livrables HTML remis à un client**
(1,79 Mo) : un catalogue de décisions d'architecture, deux rapports d'audit de passage en
production et un diagnostic d'exploitation. Ils servaient de **source d'extraction** pour les
gabarits de documents (`gabarits\documents\`) et pour les repères de
`references\BEST-PRACTICES-HTML.md`.

**Ils ont été retirés le 27/08/2026**, sur décision humaine : ce dépôt est publié, et un
livrable client entier n'a rien à y faire — nom du client, adresse professionnelle nominative
et noms d'hôtes internes compris. Le retrait couvre l'arbre **et l'historique** : les quatre
fichiers ont été purgés de tous les commits, ils ne sont plus servis par aucune empreinte.

**Ce qui en a été gardé** : les gabarits et les repères qu'ils ont produits, tous
pseudonymisés. Rien de ce qui avait été extrait n'est perdu.

**Ce que ce dossier accepte désormais** : des livrables HTML de référence **sans matière
client** — gabarits, maquettes, exemples construits pour la forge. Un livrable client se lit
là où il vit, chez le produit ou dans l'espace d'engagement privé, jamais ici.
