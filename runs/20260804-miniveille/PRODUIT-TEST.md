# Produit-test du run pilote — MiniVeille

- **Problème** : les liens de veille s'accumulent dans des onglets et se perdent.
- **Cible** : un consultant indépendant qui fait sa veille quotidienne.
- **Job principal** : enregistrer un lien avec des tags en moins de 10 secondes, le retrouver par tag, le marquer lu.
- **Palier visé** : MVP (backend FastAPI + une page web unique).
- **Ton de marque** (3 mots concrets) : encre, papier, atelier. **Contraintes reprises** : aucune (produit neuf).
