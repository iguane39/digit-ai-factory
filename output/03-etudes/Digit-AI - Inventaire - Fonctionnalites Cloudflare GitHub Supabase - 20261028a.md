# Inventaire — fonctionnalités de Cloudflare, GitHub et Supabase (28/10/2026)

Cet inventaire liste toutes les fonctionnalités que les trois index officiels énuméraient le 28/10/2026 : 205 lignes pour Cloudflare, dont Pages et Workers détaillés, 313 pour GitHub, dont Actions détaillé, 275 pour Supabase. Il sert l'étude « Digit-AI - Étude - Competences Cloudflare GitHub Supabase - 20261028a », qui en tire les compétences à construire. Les mêmes lignes vivent en données dans le fichier JSON de même nom.

Comment lire les tableaux : une ligne vaut une fonctionnalité ; une sous-fonctionnalité porte son parent. Le niveau dit ce que les forges doivent en faire : approfondir (une forge doit savoir la concevoir, tester, déployer ou auditer), connaître (la reconnaître et dire qu'elle sort de l'outillage), hors de portée (sans rapport avec les produits de la Factory). Le niveau a été proposé par un agent par plateforme, puis relu par la session pilote, qui en a changé 3 (marqués « relecture du pilot »). Le statut « disponible » est le défaut d'une page qui ne dit rien de contraire ; il ne prouve pas une disponibilité générale.
