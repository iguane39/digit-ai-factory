Réserve de sécurité & gouvernance

Idées d'architecture, jamais la machinerie. Le dépôt s'installe par des scripts et des hooks qui exécutent du code et capturent des données — hors doctrine. On en extrait des patterns de conception, jamais l'outillage. Repo cloné en lecture seule, aucun script lancé.

  • Installeurs et hooks « PreToolUse » = code tiers exécuté à chaque action.
  • Capture de secrets, d'approbations et de l'usage d'outils = collecte de données.
  • Doctrine forge : entrants jamais exécutés, aucune API tierce payante hors Claude, fichiers d'environnement jamais transmis.
